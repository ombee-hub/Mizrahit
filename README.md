# נושמים מזרחית — עיצוב מחדש (Redesign)

עיצוב ובנייה מחדש של הפורטל **נושמים מזרחית** — הפורטל הרשמי למוסיקה מזרחית ים תיכונית בישראל.
מוקאפ סטטי, רספונסיבי, בסגנון נקי-בהיר-עכשווי, RTL, מבוסס HTML/CSS/JS בלבד.

## דפים
- `index.html` — עמוד הבית (רדיו חי, חדשות, קטגוריות, מצעד)
- `news.html` — חדשות המוסיקה
- `lyrics.html` — מילים לשירים
- `downloads.html` — הורדות ופורומים
- `radio.html` — רדיו
- `register.html` — הרשמה
- `contact.html` — יצירת קשר
- `accessibility.html` — הצהרת נגישות
- `privacy.html` — מדיניות פרטיות

## קבצים משותפים
- `style.css` — גיליון הסגנון
- `app.js` — תפריט צד נייד, אייקוני רשתות, מפת אתר בפוטר
- `a11y.js` — תוסף נגישות + באנר מדיניות פרטיות
- `images/` — לוגו ונכסים גרפיים

## תצוגה מקומית
```bash
npx serve -l 8123
```
ואז פתיחת `http://localhost:8123`.
